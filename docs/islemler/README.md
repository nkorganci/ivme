# İşlem tarifleri

Tekrar eden işlerin kısa, komut odaklı tarifleri. Claude ve Codex aynı tarifleri kullanır;
AI bir işi ikinci kez elle kuruyorsa buraya tarif veya `scripts/ivme.py` alt komutu ekler.
Tarif yalnız “nasıl yapılır”ı tutar; sistem kuralı rehberde, yapılacak iş adım dosyasında
kalır. Bir komut değişince tarif aynı commit'te güncellenir.
