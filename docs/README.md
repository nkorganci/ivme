# İvme belge dizini

Görev için yalnız ilgili bölümü aç. `devam.md` oturum geçişini; klasörler kalıcı mimariyi, sözleşmeyi, içerik üretimini, şemayı, işlem tarifini, açık planı ve tasarım önerisini ayırır. Dosya adlarında küçük ASCII harfler ve `-` kullanılır; sıra numarası yalnız açık planlarda bulunur. Sayılar ve oturum geçmişi teknik sözleşmeye kopyalanmaz.

| İhtiyaç | Belge |
|---|---|
| Etkin/yarım iş ve açık işler | [Devir](devam.md), [yol haritası](plan/README.md) |
| Sistem akışı ve veri sahipliği | [Mimari](mimari/README.md), [veri kaynakları](mimari/veri-kaynaklari.md) |
| API, veri modeli, roller | [API ve mimari](sozlesmeler/api.md), [öğretmen doğrulaması](sozlesmeler/ogretmen-dogrulamasi.md) |
| Etiket, kaynak ve kanıt sözleşmesi | [Ortak etiketler](sozlesmeler/ortak-etiketler.md), [şemalar](semalar/learning-resource-v2.schema.json) |
| Kaynaklı içerik üretimi | [Ders notları](icerik/kaynakli-ders-notlari.md), [soru analizi](icerik/soru-analizi.md) |
| Akıllı Öğretmen içeriği yazımı (benzetme, aha, radar, animasyon) | [Öğretim tasarımı](icerik/akilli-ogretmen-ogretim-tasarimi.md) |
| Tekrarlanan komutlar ve kontrol | [İşlem tarifleri](islemler/README.md) |
| Çalıştırma/yayın ve soru içe aktarma | [Uygulama işletimi](islemler/uygulama-calistirma-ve-yayin.md), [soru aktarımı](islemler/soru-ice-aktarma.md) |
| Onaylanmamış ürün önerileri | [Kullanıcı rolleri tasarımı](tasarim/kullanici-yonetimi.md) |

Numaralı plan dosyaları yalnız açık uygulama işlerini anlatır. Tarihli kanıt `git log` veya `veri/` altındaki sürümlü rapordadır.
